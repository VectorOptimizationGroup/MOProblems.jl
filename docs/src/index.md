# MOProblems.jl

MOProblems.jl is a curated Julia library of benchmark problems for
multiobjective optimization. It provides benchmark constructors, objective
evaluation, registered analytical derivatives, and catalog metadata for
filtering problems by dimensions, bounds, derivative availability, and selected
structural properties.

## Contents

- [Quick Start](@ref) shows the basic construction, evaluation, derivative,
  and catalog workflows.
- [Problem Families](@ref) lists the documented benchmark families.
- [DTLZ](@ref) presents the DTLZ problems and their mathematical formulations.
- [API Reference](@ref) documents the shared types and functions.
